# 把「名称沿革」改成「沿革」:一行一段状态

> [!info] 一句话
> 名录里那些**随时间变的**东西(名称、地址、行业、统计数字)从静的一栏
> 搬进沿革表,一行记一段状态。名录只剩下「有这么一家」和它的别名。
> **同一件事只记一处。**

## 一、为什么改

现在的名录是「一家一行,格子里填属性」。可属性是会变的,于是变化只好塞进
那一个格子:

```
上海元件五厂   地址: 南京西路893号（1958），威海卫路696号（19590600）
上海无线电十七厂 地址: 北苏州路659号->董家渡路175号（196609）
华东计算技术研究所 地址: 凤阳路338->嘉定澄桥
```

一个格子里两个地点、两个年份。图上问不出「1958 年它在哪儿」——
那正是这张图要答的问题。

统计数字更明白:栏头写着 `1990`,可 **46 家的数字是 1995 年的**,
只有 1 家真是 1990 年的。后来补的 `统计年` 一栏就是在打这个补丁 ——
说明这从一开始就是**带年份的**数据,被塞进了不带年份的地方。

还有真重复。填了机构沿革之后:

```
上海无线电十四厂   机构沿革 年月 = 19600721
                名录 Start Date = 19600721   ← 同一个事实,两处都记
```

眼下一处;待判清单里那 26 条补完,就是 27 处。

## 二、表长什么样

### `沿革`(由「名称沿革」改名扩栏)

| 序 | 单位 | 自哪年起 | 名称 | 地址 | 城市 | 区 | 行业 | 职工总数 | 技术人员 | …其余统计栏 | Lat | Lng | Remark | Source |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

- **`单位`** 是钥匙:同一家的几行都写同一个**今名**,认的是它,不是这一行叫什么
- **`名称`** 是这一段用的名字
- 一行 = 从 `自哪年起` 到**下一行**之间,这家单位是什么样

### `别名`(新立,一行一个)

| 单位 | 别名 | Remark | Source |
|---|---|---|---|

别名不是一段状态 ——「上无十三」从来不是正式名称,是行文里的缩写,
没有起讫年份。所以另立一张,**一个别名一行**,不再拿顿号挤在一格里。

### `厂所名录`(缩成两件事)

留 `单位名`,外加**眼下还编不进年份的那些**(21 家有统计数字却不知是哪年的)。
年份找着了就挪进沿革表,这张表也就跟着空下去。

### 不动的

`器件`、`整机`、`机构沿革` 三张照旧。

## 三、四条规矩

> [!important] 一、空 = 沿用上一行
> 第二行只写变了的那几栏,没变的留空。**不留空就等于每行重抄一遍,
> 又回到「同一件事记两处」。**
>
> 「空」与「不知道」会不会打架?不会 —— 沿用一个不知道,得到的还是不知道。
> 「不知道」的正经去处是**头一行**。

> [!important] 二、头一行的年份可以空着
> 200 家里 **107 家没有始建年**。空着就是空着,不许编。
> 空年份的头一行读作「打我们所知的最早起,直到下一行为止」。
>
> `verify` 因此要分头尾:**头一行**允许没年份,**后面的行**必须有 ——
> 没年份就排不出先后,这一行也就没有意义。

> [!important] 三、统计数字也占一行,别的栏留空
> 1995 年数了一次人,不等于 1995 年这家厂变了。可有了第一条规矩,
> 这样的一行读起来是通的:「到 1995 年,职工 3259 人,其余照旧。」
>
> 所以 `自哪年起` 在这种行上其实是「测于」。这一层含糊是有意收下的 ——
> 换来的是不必再多一张表。
>
> **21 家的数字连年份都没有**,排不进时间线,先留在名录里等年份。

> [!important] 四、别名另立一行
> 一个别名一行,不拿顿号挤在一格。27 家有别名。
>
> 从前的名称如今各自占了沿革表的一行,不必再当别名收 ——
> 「北京有线电厂」是 1957 年起的正式名称,不是缩写。剩下真正的缩写
> (「上无十三」「国营738厂」)才进别名表。

## 四、三个真例子

### 例一:搬过家,可从没改过名

`上海元件五厂` 名录第 12 行。它一辈子一个名字,却搬过一次家 ——
**所以地址挂不到「改名」上头**,这正是沿革表不能只管名称的缘故。

| 单位 | 自哪年起 | 名称 | 地址 | 城市 | 行业 | 职工总数 |
|---|---|---|---|---|---|---|
| 上海元件五厂 | `19581021` | 上海元件五厂 | 南京西路893号 | Shanghai | 半导体 | |
| 上海元件五厂 | `19590600` | | 威海卫路696号 | | | |
| 上海元件五厂 | `19950000` | | | | | 1439 |

第二行只写地址 —— 名称、城市、行业都沿用上一行。
第三行只写人数 —— 那是量出来的,不是变出来的。

### 例二:改过名,也有统计数字

`北京有线电总厂` 名录第 153 行,沿革表已有一段。

| 单位 | 自哪年起 | 名称 | 地址 | 城市 | 区 | 行业 | 职工总数 | Source |
|---|---|---|---|---|---|---|---|---|
| 北京有线电总厂 | `19570900` | 北京有线电厂 | 酒仙桥路14号 | Beijing | 朝阳 | 电子计算机 | | 北京工业志·第四章第七节 |
| 北京有线电总厂 | | 北京有线电总厂 | | | | | | 同上 |
| 北京有线电总厂 | `19950000` | | | | | | 3259 | 同上 |

第二行**没有年份** —— 志书只说改过名,没说哪一年。按第二条规矩,
这是不许的:后面的行必须有年份。所以这一行会被 `verify` 拦下来,
逼着回原书查 —— **这是好事**:眼下这个「不知哪年改的」藏在名录里,谁也看不见。

别名表另收两行:`国营738厂`、`国营有线电厂`。

### 例三:改了名的表和名录打架

`北京计算机一厂` 名录第 36 行,`Start Date` 写着 **1970**;
可沿革表里它 **1957** 年就叫「北京市服务联社电器制造厂」了。

**两处对不上,而现在没有一道关卡会发现。** 并成一张之后,头一行的年份
只能有一个,这个矛盾当场就得了断。

## 五、迁移怎么做

一支脚本,**先空跑**,报出它打算写什么、以及打不定主意的有哪些:

1. 名录 200 行 → 沿革表 200 个头一行(年份取 `Start Date`,没有就空着)
2. 现有 83 行名称沿革并进去,按 `单位 + 自哪年起` 对齐;同年同单位的合成一行
3. 3 家地址里塞了两个地点的,拆成两行
4. 46 家带 `统计年` 的数字各占一行
5. 27 家的别名拆进别名表,**一个一行**
6. 21 家没年份的统计数字留在名录里

粗估 290 行上下。**冲突不自动判**,一律列进 `待判清单.md`,譬如例三那种。

## 六、代码要改哪儿

| 哪儿 | 改什么 |
|---|---|
| `toxlsx.py` | 读沿革表要按 `单位 + 自哪年起` 排序、沿用空格;新增别名表的读写 |

| 待核工作簿 | 「名称沿革」那张要跟着扩栏 |

## 七、还没定的

- **名录会不会真空下去。** 21 家没年份的先留着;若始终查不着年份,
  这张表就长期留着一小撮 —— 也可以改成「挂在头一行、备注写明年份未详」,
  那样名录就能整个撤掉。**先按留着办,回头看着办。**
- **`城市` 要不要放进沿革表。** 厂不会搬到别的市去,放进来几乎永远只写一次。
  放着是为了「一件事只记一处」,代价是多一栏。
- **表宽。** 沿革表要二十栏上下。Excel 里横拖得远 —— 冻结前四栏能缓一缓。
