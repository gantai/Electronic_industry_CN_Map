# 测试样张

都不是真书,是照志书的行文**编**出来的,用来盯住抽取逻辑。

`上海电子仪表工业志.md` —— 三页仿《上海电子仪表工业志》体例的转换稿,带
`<!-- p.N -->` 页码锚点。盯的是厂名、始建年、名称沿革、门牌、1990 年统计块、
器件与整机记录、协作关系,以及几处容易出错的地方 ——

- 「1985年12月撤销,并入上海无线电十九厂」讲的是元件十四厂的终局,
  **不可**给十九厂添个终止年,也不可写进十九厂的 Founder
- 「该机与上海无线电十三厂协作生产」只算 TQ-16 的协作,与下一台 DJS-130 无关
- 「一九六五年改称」这类中文数字纪年要折算成 19650000

`北京转换稿-gb18030.md` —— 换一种编码、换一座城、没有页码锚点的稿子。

`北京-压平标题.md` —— 照《北京工业志·电子志》2001 第三章的体例:「第三章」
「第一节」「一、」一律写成 `##`,通篇一个页码也没有。这两样别处转来的稿子上
最常见,出处只能退到篇章节路径,所以层级不能靠数井号。

扫描件 → Markdown 那一段归 zhiconv 管,不在这个仓里,这里也就不验它。
