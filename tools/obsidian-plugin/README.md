# 电子工业地图流程 · Obsidian 插件

《电子工业地图流程》那八步,在 Obsidian 的侧栏里按钮点着走,不必再开 PowerShell。

## 先说清楚它不是什么

**这个插件不自己抽数据。** 抽数据的是仓库里的 `gaz`(Python)—— 誊录的规矩、
名字怎么认、隶属怎么定,全在那边,几千行,都有测试压着。插件只做三件事:

1. 把八步摆成按钮,该填的参数用表单问清楚;
2. 替你把命令敲对(路径带空格、带中文、带书名号,这边按数组传,不必操心引号);
3. 把跑出来的字接回面板里,不必切窗口看。

所以:

* **Python 还是要装**,openpyxl 也是。装了没有,面板上「本机装了什么」那一条会说。
* **只在桌面版能用**。手机、平板上的 Obsidian 跑不了外部程序 —— 装了也不会出现。
* **核对那一步代不了。** 「取否」写 `y` 的行才收,那是判断,不是誊录。插件能替你
  把待核工作簿开起来,开完还是得你一行一行看。
* **重跑一本核过的志书,核的是格子不是单位。** 第三步会自己看出来:早已在总表里
  的行标上「已收」,这一遍新认出来的摆成一张「补全已有记录」。117 家的一本,重跑要核的
  是一百二十来个格子,那 103 家连看都不必看。详见《电子工业地图流程》。

## 装

一、装进库(库是你在 Obsidian 里打开的那个文件夹,不是仓库):

```powershell
cd D:\Coding\CN_Map\tools\obsidian-plugin
.\装.ps1
```

**这一步不用 Node,也不用 npm。** `main.js` 是打包好跟着仓库一起来的,
装插件只是把三个文件抄进库里。只有改了插件源码要重新打包时才用得着 Node。

库不在 `D:\Archive` 的话:`.\装.ps1 -Vault "E:\别处"`。

> [!note] 万一 PowerShell 不让跑脚本
> 报「禁止运行脚本」就先办一次(只影响你自己这个账户):
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
> 不想改这个设置,就自己抄三个文件 ——
> `main.js`、`manifest.json`、`styles.css` 抄进
> `<库>\.obsidian\plugins\dianzi-gongye-ditu\`,一样的。

二、Obsidian 里 **设置 → 第三方插件** 把「电子工业地图流程」打开
(头一回还要先关掉「安全模式」)。

三、**开面板,按顶上那张卡片的「认一下仓库」。**

只问一样:仓库在哪儿。**卡片一开就自己去找** —— 翻几个盘的浅处,找搁着
`tools\gazetteer\gaz.py` 的那一层。`D:\Coding\CN_Map` 这种搁得浅的,一开就填好了。

找不着(仓库搁得深)就自己粘:在资源管理器里打开 CN_Map,**点一下地址栏空白处**,
整条路径会变成可复制的文字,复制过来粘进那一栏。粘完它立刻验一验对不对。

> [!note] 「挑个文件」那条路修好了
> 卡片底下那行「或者挑仓库里随便一个文件」从前**按了没反应** —— 用的是网页
> 那套藏起来的 `<input type=file>`,在 Electron 里时灵时不灵。如今改用
> Electron 自己的 `dialog.showOpenDialog`(见 `src/dialog.ts`);
> 万一这套 Obsidian 里连它也没有,**会当场说一句**,不再是按下去什么也不发生。
> 粘路径与「自己找」照旧都在。

余下几样它自己认,不必你填:

| 自己认的 | 怎么认的 |
| --- | --- |
| python 怎么敲 | 挨个试 `python`、`py`、`python3`,谁先应声用谁 |
| 在哪一支上干活 | 问 `git rev-parse --abbrev-ref HEAD` |
| 库里厂所笔记那一支 | 库底下有 `厂所\` 就用它 |
| 转换稿目录 | 空着,也就是仓库里的 `转换稿\` |

认完这几样会摆出来给你看一眼,再按「认下来,开工」。

> [!note] 那些设置后来还改得动
> **设置 → 第三方插件** 底下,左边一列拉到最下头有个「电子工业地图流程」,
> 每一栏都在那儿。`Ctrl+P` → 「认一下仓库」也能把那张卡片再开出来。

### 更新:**在面板里按一下就是**

装过一回之后,更新不必再开 PowerShell:

面板末一段**「更新与上线」**里,挨着的两条按下去就是:

1. **拉取更新**(把仓库拉到最新);
2. **装上新的**。

拿新的下来、把新的装上,本是一件事的两半 —— 所以摆在一处,拉完了一眼就看见
还得装。

第二条干的就是 `装.ps1` 那件事 —— 抄那三个文件进库,**接着自己重载插件**。
重载是要紧的一步:只抄文件不重载,面板上仍是旧的,看着就像什么也没变。

那一行还兼报状态,不必猜:

| 它说什么 | 意思 |
| --- | --- |
| 插件是仓库里那一份,没有更新要装 | 装着的跟仓库里逐字节一样 |
| **仓库里的插件比装着的新** | 按它(那一条会亮起来) |
| 库里还没装过这个插件 | 头一回,得用 `装.ps1` |
| 仓库里找不着打包好的 main.js | 先「拉取更新」 |

> [!note] 为什么非有这一行不可
> 从前更新要三样:拉取 → 开 PowerShell 跑 `装.ps1` → 回 Obsidian 把插件关一下
> 再开。漏掉任何一样,面板上看着就是**什么也没变** —— 而且看不出是没装上,
> 人只会以为改动没生效。为这件事来回过三趟。
> 如今状态直接写在那一行上,按钮也在那一行。

## 用

**除了装更新,动手一律走这儿。** 不必开 PowerShell,也不必记命令 —— 面板上
没有的功能就是缺的功能,缺了该在这儿添一条,不该打发人去敲命令行
(`tests/steps.test.mjs` 里有一条盯着:凡是要人动手的 `gaz` 子命令,
面板上都得有一条)。

左边栏那个地图图标,或 `Ctrl+P` → 「打开流程面板」。

面板从上往下就是干活的次序:

| 段 | 里头是什么 |
| --- | --- |
| **设置**(顶上,没有小标题) | 仓库在哪儿、库里哪一支、python 怎么敲、在哪一支上干活 |
| **更新:先看手里这份新不新** | 看状态 → 拉取更新 → 装上新的(更新插件) → 本机装了什么 |
| **抽录** | 第一步转 PDF、第二步看稿子成色、第三步抽成待核工作簿 |
| **核校** | 第四步核对、第五步并进总表、第六步验一验、认下、理沿革表 |
| **落点** | 第七步落点草稿、按路排的落点草稿、核落点 |
| **更新线上地图** | 提交改动 → 第八步合进 main;底下是库里那几条 |

「库」那两栏的路径还能**从库里的文件夹里挑**,不必自己打。

> [!note] 头一段与末一段各自是一件事
> 头一段四条都在答同一个问题:**手里这份是什么时候的,该不该先更新** ——
> 从前「动手之前」与「更新」分作两段,可看状态看的就是该不该更新。
> 「拉取更新」与「装上新的」必得挨着:拿新的下来跟把新的装上是一件事的两半。
>
> 末一段上头两条是把改动发出去(**只有「合进 main」那一条能让线上那张图变**),
> 底下三条是库里那一摊 —— 那几条不动线上的图,只是笔记与工作簿之间来回倒。

> [!important] 面板的样子在 `src/steps.ts` 的 `PANEL` 里,一处说了算
> 从前分两处管:哪一步归哪一段写在每一条 `Step` 上,git 那几条另在 `view.ts`
> 里手写 —— 两处对不上就看不出来(「拉取更新」与「装上新的」一度隔着一个
> 小标题)。添一步、挪一段都改 `PANEL`;`tests/steps.test.mjs` 盯着
> 「每一步都摆着,且只摆一回」。

每一步也各是一条命令,`Ctrl+P` 敲得到,配得上快捷键。

**动手之前它会把要跑的那几句摆出来**,看清楚再点。只读的那几步(看状态、验一验)
不问,直接跑 —— 它们一个格子也不动。

### 一份稿子,从头带到尾

第二步挑一次稿子,底下几步就都跟着它走:

| 步 | 那一栏 | 从哪儿来 |
| --- | --- | --- |
| 第一步 转 PDF | 稿子写到哪儿 | 空着就照 PDF 的名字写进 `转换稿` |
| 第二步 看成色 | 稿子 | 上一步转出来的那一份 |
| 第三步 抽 | 稿子 | 同上 |
| 第四步 核对 | 待核工作簿 | 跟稿子同目录同名,自己推出来 |
| 第五步 并表 | 核过的工作簿 | 同上 |
| 第七步 落点 | 这本志的名字 | 稿子的文件名去掉后缀 |

带过来的都还能改 —— 只是不必再挑一遍。

> [!note] 第三步用的是 `gaz book`,不是 `gaz volume`
> 两条命令干的是同一件事,只是找稿子的法子不同:`volume` 按名字里的一截去搜,
> `book` 指名道姓。面板上第二步已经把那一份挑出来了,再要人打一遍「稿子名里的
> 一截」没道理 —— 所以这儿走 `book`。命令行上照旧两条都在,按名字搜有按名字
> 搜的方便。

### 挑文件:**列着让你挑**

要挑的文件都在已知的地方,所以表单里**直接列出来**,一步也不经系统的对话框:

| 哪一栏 | 列的是哪儿 |
| --- | --- |
| 稿子(第二、三步) | 仓库的 `转换稿` 目录 |
| 待核工作簿(第四、五步) | 同上 |
| 志书 PDF(第一步) | **整个 Obsidian 库** —— 原件本来就该搁库里 |

库里那一份是 Obsidian 自己的索引(它本来就认得 PDF、还能翻),
不读磁盘、不弹窗,一定列得出来。

列里没有(还没转稿子、原件搁在移动硬盘上)就走另两条:**「浏览…」**开系统的
对话框,或者把**整条路径**贴进那一栏 —— 在资源管理器里点一下地址栏空白处,
路径就成了可复制的文字。

**并过的工作簿不在列里** —— 第五步并完,它自己挪进 `转换稿\已并入总表\`,
那一层挑稿子时不列。于是列里剩下的就是还没办完的:工作簿是二进制,
看不出里头的「取否」打没打过,不挪开,隔几天回来只能一份份开开来看。

> [!note] 「浏览…」从前按了没反应,栽过三次
> 病根是拿网页那套藏起来的 `<input type=file>` 去 `.click()`:要弹出系统对话框
> 得 Electron 那头许可,而 Obsidian 并不保证 —— 不报错、不弹窗,什么都不发生。
> 藏法改过一轮(`display:none` → 挪到屏幕外)仍不保准,因为病根不在藏法。
>
> 如今改用 Electron 自己的 `dialog.showOpenDialog`(`src/dialog.ts`):
> 新版 Obsidian 搁在 `@electron/remote`,老版搁在 `electron.remote`,两处都试;
> **两处都没有就当场说一句**,由人走另两条路。
> 静悄悄什么也不发生,是这三次里最坏的一样 —— 人只会以为自己点错了。

### 上线那一步拦得比别处紧

合进 main 是唯一能让线上那张图变的一步,所以:

* 先摆出**这一支比线上多哪几条提交**,没有就不让跑;
* 有改动没提交就**拦下来** —— 底下要切到 main,带着没提交的改动切过去,
  轻则切不动,重则把它们带到 main 上;
* 那一串六句写死在 `src/gitops.ts` 里,**少一句都不行**。
  从前手敲漏过 `git merge --ff-only origin/main`,本地 main 落后三十七个提交,
  推不上去;更糟的是合进去的压根不是当时要发布的那个改动。
  `tests/steps.test.mjs` 里专门有一条盯着它。

## 改

**改源码才要 Node。** 只是用插件的话,上头那一节就够了。

```powershell
cd D:\Coding\CN_Map\tools\obsidian-plugin
npm install
npm run check      # 类型、测试、打包,一趟过
```

`npm` 说「不是可运行的程序」,就是这台机器没装 Node(或者装完没开新终端 ——
PATH 只有新起的程序看得见)。装法见《电子工业地图流程》的「装机」一节。
打包出来的 `main.js` 是要提交的:提交了,别的机器不装 Node 也能装插件。

`src/steps.ts`、`src/gitops.ts`、`src/runner.ts`、`src/setup.ts`
**一行 Obsidian 的东西也不碰** —— 拆开就是为了测得动:命令拼错了在插件里
看不出来,跑起来才知道,而那时候工作簿已经动过了。
添一步、改一个参数,顺手在 `tests/steps.test.mjs` 里补一条。

`src/runner.ts` 里那个 `PYTHONIOENCODING=utf-8` 别删:Windows 上 Python 往管道里
写字用的是系统的 GBK,这边拿 UTF-8 读就是满屏乱码,而且不报错。
同一处那三个 `GIT_CONFIG_*` 也别删:git 默认把中文文件名转义成八进制
(`?? "\350\275\254\346\215\242\347\250\277/…"`),提交那一步的清单、
拉取那一步的拦阻理由全是文件名 —— 印成那样等于让人对着一串数字猜自己的稿子
叫什么。那三个变量等于只对这一次加一句 `-c core.quotePath=false`,
不动用户自己的 `~/.gitconfig`。

喂输出那一段里,**子进程收尾时要把末尾没换行的那一截吐出来**。从前只在遇着
`\n` 时才喂,末一行不带换行就压在缓冲里丢掉 —— traceback 的末行、没写完就退出
的那一行,恰恰是最要紧的几行。

**参数一律按数组传,不拼成一行字。**`《北京工业志·电子志》2001 第四篇.md`
书名号、中文、空格三样全占 —— 拼成一行就得自己操心引号,那正是 PowerShell 里
最容易出岔的地方。

改了参数,记得回去改 `tools/gazetteer/电子工业地图流程.md`。**那份文档是正本**,
这个插件只是它的一个壳子。
